## Changes made in this project

The XES file remains unchanged. Derived outputs flatten nested case and event attributes; standardize blanks and UTC timestamps; flag out-of-window events and sequence anomalies; select a defined material-purchasing cohort; and calculate elapsed calendar times, counts, coverage and percentiles. Derived CSVs, figures and narrative are this project's analysis of the cited dataset. Synthetic edge-case records are used only inside unit tests, never in the analysis.

Source IDs and monetary values were anonymized by the publisher. The manufacturer is unnamed, so this project retains that anonymity. Anonymized values are not presented as original spend, savings or ROI. The source includes goods and services across selected subsidiaries; the main analytical cohort represents the narrower set described in the methodology, not the whole organization.

## Files for GitHub

The official compressed source, metadata, source manifest, compact derived outputs, scripts, SQL, figures and documentation are included in the project package. The local SQLite database is excluded because it is large and can be rebuilt. `analysis_cases.csv.gz` contains all main-cohort case metrics; the preview CSV is a convenience, not the analysis population. Keep the source citation and this notice when sharing adaptations.
